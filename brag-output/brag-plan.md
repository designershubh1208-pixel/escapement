# Brag Plan: Escapement (DeFAI Sentinel)

## What is this app?
Escapement (DeFAI Sentinel) is an enterprise-grade deterministic financial firewall that intercepts autonomous AI agent transactions to prevent prompt injections, hallucinated pricing, and treasury drain before capital moves.

## The angle
The corporate nightmare of 2026: developers giving autonomous agents corporate credit cards and API keys. Escapement turns the naive "AI with a wallet" risk into a mathematically bounded fortress: *Probabilistic models must never hold economic execution rights.*

## Hook (first 2-3 seconds)
A stark warning on an obsidian canvas: "You gave your autonomous AI agent a corporate card..." followed by an agent attempting an unconstrained ₹250,000 transaction with prompt injection exploit text.

## Key moments (the middle)
- The instant deterministic interception: Escapement's Mathematical Firewall activates with a fail-closed lock, freezing the prompt injection dead in its tracks.
- Live DOM anti-arbitrage scraping & strict policy limits: validating real prices against Amazon/Flipkart and enforcing hard ₹500 spending ceilings.
- The 3-tier Bento dashboard showing the dual-rail EVM ledger, immutable SHA-256 audit logs, and human-in-the-loop cryptographic approval gate.

## Outro / punchline
"AI reasons. Policy decides. Code constrains."
The obsidian & sapphire blue Escapement brand reveal with the CTA: "Never let an LLM hold your treasury. Deploy Escapement."

## User flow worth showing
Agent creates unsigned payment intent → Escapement Deterministic Firewall evaluates invariants (price verification, velocity caps, merchant allowlist) → High-value anomaly detected → Intercepted & escalated to Human Gateway → Scoped settlement executed only after explicit cryptographic authorization.
